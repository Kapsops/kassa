# Семейная касса

Однофайловое HTML-приложение для общих расходов и взносов участниц P и O.

Открывается онлайн: https://kapsops.github.io/kassa/

## Запуск

Откройте `index.html` в браузере. Для работы с проектом запустите Kimi Code из этой папки:

```bash
kimi
```

Скопируйте этот текст первым сообщением:

> Изучи index.html. Это однофайловое приложение «Семейная касса» для P и O.

> Важные правила:

> Сначала расскажи, как устроен файл, ничего не изменяя.

## Данные и безопасность

В архиве нет реальных операций, паролей или ключей. Данные подтягиваются через существующую синхронизацию после ввода общего пароля в настройках кассы.
